## 水印盒 v1.6.0

水印位置可以拖了，下载也更安全了。

### ✨ 新增

- **拖动定位水印**：单个模式下，直接在预览图上拖动水印到任意位置，不再局限于九宫格
  - 手指按住水印即可拖动，松手即生效
  - 拖完仍可点击九宫格按钮，让水印回到规整的方位
  - 位置会随导出精确保留（预览看到什么位置，导出就是什么位置）
- **应用内下载校验**：下载完成后自动校验安装包，不通过则拒绝安装并删除文件
  - **SHA-256**：与 GitHub 提供的摘要比对，能发现下载损坏
  - **包名**：必须与当前应用一致，防止下载到别的应用
  - **签名**：与已安装版本比对，确保是同一把私钥签发的包 —— 这是防篡改的根本保证
  - 校验失败时会说明原因（文件损坏 / 非法文件 / 签名不符）

### 🔧 修复

- **修复对角线水印在长方形图片上覆盖不全**
  - 此前横向长图只有中间约 26% 的区域有水印，两侧大片空白
  - 现在会均匀铺满整张图（覆盖率 26% → 96%）
- **修复对角线与平铺的旋转逻辑颠倒**
  - 对角线：现在是**整体斜铺**（水印呈平行的斜向条带，且铺满四角）
  - 平铺：现在是**逐字旋转**（每个水印按设定角度自转，网格排列保持水平）
- **修复单个模式在画面四角旋转时水印被甩出画面**
  - 此前旋转是绕「画布中心」进行的，水印放在角落时会绕着画面中心公转
  - 现在改为绕水印自身的中心旋转，放在哪里都是原地打转

### ⚡ 优化

- 设置页在代码层面做了拆分，为后续维护减负（对使用无影响）
- 构建流程加入静态检查（Android Lint），并修复了敏感信息自查脚本的一处漏检
