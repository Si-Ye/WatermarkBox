# 版本说明

本目录存放**每个版本对外发布的说明**，用于 GitHub Release 页面。

## 约定

- 文件名即 tag 名：`v1.5.0.md` 对应 tag `v1.5.0`
- 纯 Markdown，GitHub 会直接渲染
- **结构统一**（见下方模板），按「新增 / 修复 / 优化 / 变更」分段
- 由发版者在该版本**发布前**创建

## 为什么独立成文件

早期 Release 说明由 CI 临时拼接（只有下载表格与校验值），
**不含「更新了什么」** —— 而这恰恰是用户最关心的。

改为「一版一文件」后：

- 内容完全可控，能写清**新增/修复/优化**三类信息
- 可从 git 历史核对，避免遗漏
- 归档清晰，便于日后回溯某一版到底改了什么

## 模板

```markdown
## 水印盒 vX.Y.Z

一句话概括本版主题。

### ✨ 新增

- 新功能 A
- 新功能 B

### 🔧 修复

- 修了什么问题（用户视角描述现象）

### ⚡ 优化

- 体验改进、性能提升

### 🔄 变更

- 行为调整、破坏性变更（如有）

### 📦 下载

| 文件 | 说明 |
|---|---|
| `WatermarkBox-X.Y.Z-release.apk` | **推荐**，正式包 |
| `WatermarkBox-X.Y.Z-debug.apk` | 调试用，含额外日志 |

> **注意**：两个包签名不同，换装需先卸载。

### 系统要求

Android 8.0（API 26）及以上
```

## 维护流程

1. 发版前：新建 `vX.Y.Z.md`，按模板写清变更
2. 打 tag 推送
3. CI 自动读取这个文件作为 Release 说明并附上 APK

**注意**：下载表格里的版本号与校验值由 CI 自动补全，
文件里手写的那份作为「无 CI 时的人工兜底」，两者内容一致即可。
