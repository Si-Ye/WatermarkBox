## 水印盒 v1.5.0

界面支持中英双语，并新增应用内「检查更新」。

### ✨ 新增

- **中英文界面切换**：设置 → 其他 → 语言，可选「跟随系统 / 中文 / English」，切换后界面立即生效，无需重启
- **检查更新**：自动检测 GitHub 上的新版本，展示版本号与更新说明，支持一键跳转下载
  - 启动时自动检查（每天最多一次，可在设置中关闭）
  - 入口有两个：设置 → 其他 → 检查更新；关于页顶部的版本徽章
- **应用内下载安装**（实验性）：直接在应用内下载并安装新版本，无需跳转浏览器
  - 默认关闭。开启时需要系统「安装未知应用」权限
  - 关闭时应用完全不触碰该权限

### 🔧 修复

- 修复更新说明以源码形式显示的问题：此前 GitHub Release 里的 Markdown 标记（`#`、`|`、`**`、反引号）会原样展示，现在会正确渲染为标题、表格、加粗与代码块
- 修复应用内下载安装时报「解析软件包时出现问题」的问题
- 修复开启「应用内下载」时，若未真正完成授权，开关仍显示为开启的问题

### ⚡ 优化

- 更新说明对话框支持滚动，超长说明不会再撑出屏幕

### 🔄 变更

- **导出目录统一为 `Pictures/WatermarkBox`**（原为 `Pictures/水印盒`）
  - 旧目录中的图片**仍可正常读取**，不受影响
  - 新导出的图片会保存到新目录
