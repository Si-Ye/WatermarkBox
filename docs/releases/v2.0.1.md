## 水印盒 v2.0.1

2.0 之后的一轮收尾：文案更准、无障碍可用、关于页多了一行「你装的是哪个包」。

### ✨ 新增

- **关于页底部显示构建信息**
  - 一眼看出装的是 **Debug 版**还是 **Release 版**，并显示**实际安装包名**
    （同一应用常有多个可安装产物，反馈问题时不必再来回问）
- **主创头像与昵称改为运行时从 GitHub 取**
  - 换了头像、改了昵称，应用**不必发版**就能跟上（缓存 6 小时）
  - 取不到时自动回退到内置的头像与昵称 —— 离线、限流都不开天窗

### ⚡ 优化

- **无障碍（第一批）**
  - 参数面板把手：读屏现在会念出「是否展开」以及「可以点击」
  - 设置页分类页签：会念出「当前选中哪个分类」
  - 批量页翻页圆点：以前完全没有标签（读屏一片沉默），现在会念「第 N 张」；
    触摸目标也从 20dp 撑到 **48dp**（视觉不变），手部不便的用户才点得中
- **代码质量**：lint 历史欠账从 42 条清到 **1 条**（剩下的一条在 baseline 里写明了理由：
  自适应图标目录保留 `-v26` —— 实测去掉后 AAPT 会构建失败）

### 🔄 变更

- **文案更准**：「不联网 / 不申请网络权限」的说法**本来就不准确**
  （应用一直有网络权限，用于「检查更新」）。
  现在统一改为「**只下载、不上传**」—— 图片处理完全在本机，
  应用不上传任何数据。

### 📦 下载

| 文件 | 说明 |
|---|---|
| `WatermarkBox-2.0.1-release.apk` | **推荐**，正式包 |
| `WatermarkBox-2.0.1-debug.apk` | 调试用，含额外日志，体积较大 |

> **注意**：两个包签名不同。装过其中一个后换装另一个，需先卸载（应用数据会丢失）。

### 系统要求

Android 8.0（API 26）及以上
