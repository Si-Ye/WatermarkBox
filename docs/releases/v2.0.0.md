## 水印盒 v2.0.0

隐藏水印大升级，顺手把整套交互做顺了。

### ✨ 新增

- **隐藏水印：多一条通道**
  - 除 EXIF 之外，新增 **XMP** 元数据通道 —— 有些工具只清其中一个，两条一起写更耐折腾
- **隐藏水印：能验证真伪了**
  - 水印内容带 **HMAC 签名**，检测时会说清三种状态：*已验证 · 本应用签发* / *无效 · 可能被伪造* / *无法验证（旧版本或明文元数据）*
  - 检测页新增「**用 DCT 验证签名**」开关：EXIF 是明文、没签名，开启后会用频域复查一遍
- **两条通道可各自开关**：EXIF / XMP 一路、DCT 频域一路，按需取舍
- **直角旋转也能认**：图片被转过 90° / 180° / 270° 后仍能检出
- **检测页可自选检测项**：检查 EXIF、检查频域、尝试全部强度、尝试 4 个旋转方向、用 DCT 验签 —— 想快就快、想全就全
- **使用教程与新手引导**
  - 设置 → 其他 → **使用教程**：8 节图文教程，中英各一份
  - **新手引导**：首页 5 步，聚焦式高亮 + 指向气泡；教程页底部可「重新过一遍」
- **导出进度**：导出时显示进行到哪一步（解码原图 → 渲染水印 → 隐藏水印 → 保存）

### ⚡ 优化

- **隐藏水印画质更好**：按块活动度自适应强度，同等抗压缩能力下峰值改动降约 70%
- **大图保护**：导出 / 批量 / 检测会先算内存，放不下时**明确告知**（而不是卡住或崩掉）
- **界面更清爽**：所有超过一行的说明统一收进 ⓘ 图标，点击才展开
- **全面流畅度优化**
  - 预览渲染移出主线程、位图双缓冲复用（干掉每帧约 3 MB 的原生分配）
  - 批量页左右翻页**预先解码相邻图片**，不再闪加载圈
  - 修复拖动水印 / 拖动参数面板时的卡顿感
  - 页面切换、面板展开、列表增删都补上了**短促**的过渡动画（200ms 级别）

### 🔄 变更

- **导出设置拆分为两处**：编辑页右上角 ⚙ 只改**全局默认值**；右下角「导出」弹的是**本次参数**，改完不影响默认值

### 🐛 修复

- 教程文档的 Markdown 渲染错误（加粗标记跨行导致 `**` 原样显示；嵌套列表丢缩进）
- 拖动水印时手势被反复重建，表现为「拖到一半卡住」
