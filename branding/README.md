# branding —— 图标源文件

## 当前图标（2026-10-28 起）

`ic_launcher.png`（1254 × 1254，GPT-Image2 生成的材质化图标）是**唯一母版**：
紫色→蓝色渐变底 + 白色相框 + 山形 + 青色水滴，自带圆角、四角透明。
旧的手绘 SVG 图标（盒子 + 琥珀色水滴 + 深蓝底）已随 2.3.0 一起废弃删除。

## 母版怎么变成 App 里那些图

| 产出 | 路径 | 由来 |
|---|---|---|
| 传统启动器图标 | `app/src/main/res/mipmap-*/ic_launcher.webp` | 母版直接缩放（保留自带圆角与透明角；老启动器不做蒙版） |
| 圆形图标 | `mipmap-*/ic_launcher_round.webp` | 与上一行同一份母版缩放（圆形桌面会自己加圆蒙版，不必另做裁切） |
| 自适应背景 | `mipmap-*/ic_launcher_background.webp` | 母版**放大 1.7 倍 + 高斯模糊**后中心裁切，不透明 |
| 自适应前景 | `mipmap-*/ic_launcher_foreground.webp` | 母版缩到画布 **70%** 居中，四周透明 |
| 主题图标（单色） | `mipmap-*/ic_launcher_monochrome.webp` | 白色剪影（相框 + 山 + 水滴），同样缩到 70% |
| App 内品牌图 | `app/src/main/res/drawable-nodpi/ic_app_logo.webp` | 母版缩到 432px（首页 88dp、关于页 84dp，3x 屏也够） |

尺寸：传统图标 48/72/96/144/192；自适应三层各 108/162/216/324/432（108dp）。

## 为什么前景是 70%，而不是满幅

这是踩过一次的坑，**别再改回满幅**：

- 自适应图标启动器只显示中间 **72/108dp ≈ 66%**（安全区），其余被圆/圆角方蒙版切掉。
- 母版的白色相框几乎贴着母版边缘。前景若满幅，相框的四个圆角正好落在安全区外，
  被蒙版削掉一块 —— 视觉上像图标缺了个角。
- 70% 是算出来的：缩到 70% 后相框圆的半径 `0.70 × 0.707 ≈ 0.495`，刚好落在
  蒙版半径 0.5 之内。**再大就开始切相框，再小图标显得小。**
- 前景变小后会露出背景层，所以背景层不能用纯色（会和母版的渐变撞出接缝），
  而是「母版放大 1.7 倍 + 高斯模糊」—— 同源颜色，接缝看不见。

## 改图标时注意

- 六个 mipmap（传统/圆形/背景/前景/单色）+ 一张 `ic_app_logo` 必须**一起换**，
  只换其中一部分会出现「桌面是新图标、关于页还是旧的」。
- 单色层不能用母版阈值化生成：母版的高光有条纹，阈值化后会留下一堆碎片，
  必须重绘（或直接用矢量）。
- `ic_app_logo` 本身带圆角，调用方**不要再 clip**（见 `HomeScreen.AppLogo` 注释）。
- 换完必须在真机/模拟器上看一眼**启动器**（蒙版效果只有启动器才体现），
  再看一眼关于页与首页 AppLogo。命令见 `docs/build-artifacts.md` §5。
